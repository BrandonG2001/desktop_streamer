Virtual Desktop Streamer (Rust) 1.2.1

This is an independent Rust port of the Virtual Desktop Streamer that lets a Quest (or other
Virtual Desktop headset) stream and control this computer's desktop.

Before you continue:

* Quit the official Virtual Desktop Streamer if it is running. Both programs use the same network
  ports (TCP 38810-38840) and keyboard shortcuts, so only one of them can run at a time.

* FFmpeg is required for video streaming. If it is not installed, setup can install it for you
  with winget (Gyan.FFmpeg). A copy placed next to desktop_streamer.exe is also used.

* PC audio works on its own: in "VR headset only" mode the PC speakers are muted while a headset
  is connected and restored afterwards. Microphone passthrough needs a driver: either the
  Virtual Desktop audio driver from the official Virtual Desktop Streamer, or a virtual audio
  cable such as VB-Audio Virtual Cable (https://vb-audio.com/Cable/).

* VR game streaming (SteamVR / OpenXR) is not supported by this version; desktop streaming,
  video playback, audio, microphone, keyboard, mouse and laser-pointer input are.

After installation the settings window opens. Add the account you use on the headset in the
ACCOUNTS tab (for Meta Quest: your Meta user name), then connect from Virtual Desktop in the
headset. Closing the window keeps the streamer running in the notification area; use "Exit" in
the tray menu to quit.

Settings and logs are stored in %APPDATA%\Virtual Desktop Streamer (Rust).
